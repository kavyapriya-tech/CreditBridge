\# CreditBridge



\*\*Explainable Dynamic Risk Assessment for Underserved Credit Segments\*\*



CreditBridge is a decision-support prototype that scores loan applicants who

lack traditional credit history using permitted alternative signals (income

stability, transaction/cashflow behavior, utility/rent payment consistency,

etc.), classifies them into Low / Medium / High risk, and explains the

prediction in plain language.



\*\*This is a decision-support tool for a human reviewer, not an automated

approval/denial system.\*\*



\## Tech Stack



\- Backend: FastAPI (Python)

\- Frontend: React (Vite)

\- Database: PostgreSQL

\- ML: scikit-learn (Logistic Regression), coefficient-based explainability



\## Architecture



React frontend (localhost:5173)

&#x20; -> REST (JSON) ->

FastAPI backend (localhost:8000)

&#x20; ->

Risk Service (loads trained sklearn model)

&#x20; ->

PostgreSQL (applicants, assessments)



\## Dataset



The model is trained on a synthetic dataset (3,000 rows) generated by

ml/generate\_data.py. No real applicant data is used anywhere in this

project. Features and the risk-scoring rationale are documented in that

script's comments.



\## Model



Logistic Regression, selected over Random Forest by ROC-AUC on a held-out

test set (see ml/train\_model.py for the comparison and metrics).



Explainability (ml/explain.py) computes each applicant's top contributing

factors directly from the model's coefficients times their feature values,

real model evidence, not a generated summary.
